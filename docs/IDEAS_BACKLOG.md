# Ideas Backlog

This backlog intentionally expands beyond the initial strict scope to discover high-impact features.

## Analytics
- Event burst detector per domain/entity.
- Recorder growth attribution by integration from real recorder statistics.
- Automation effectiveness score (triggered vs. useful outcomes).

## Reliability
- Automation dead-path detector (conditions almost never pass).
- Service-call failure hotspot map.
- Device flapping detector (rapid unavailable/available transitions).

## Privacy
- Configurable masking profiles (safe-share, team-debug, local-dev).
- Mask preview diff view before export.
- Stable pseudonyms with per-export salt options.
- Privacy coverage drill-down with entity-level review filters.

## AI Assistance
- LLM-oriented context packs (short, medium, deep).
- Prompt templates for debugging, optimization, and architecture review.
- Suggested next-actions generated from analyzer findings.

## UX
- Recommendation inbox with status tracking (new/accepted/dismissed).
- Explain-why cards for each recommendation.
- Internationalization bundles (EN baseline, DE next).

## Developer Tooling
- Diagnostics UI for support handovers and Codex context.
- UI render snapshot export for reviewing panel readability.
- Self-check that explains missing configuration such as `HCX_MASK_KEY`.
